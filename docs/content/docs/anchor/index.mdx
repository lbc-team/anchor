Anchor 是构建 Solana 程序（智能合约）的首选开发框架，它简化了编写、测试、部署和与 Solana 程序交互的过程。

Anchor 框架帮助开发者更快地构建生产级的应用程序，同时通过内置的安全功能减少潜在漏洞。
