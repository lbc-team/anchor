## 什么是 Token Program？

在 Solana 上，有两个主要的 Token Program（由 [Anza](https://www.anza.xyz/) 开发，之前是 Solana Labs）：

1. [Token Program (原始版)](https://github.com/solana-program/token)
   - 提供基本的代币功能（铸币、转账等）
   - 不可变且广泛使用
2. [Token Extension Program (Token 2022)](https://github.com/solana-program/token-2022)
   - 包含所有原始 Token Program 的功能
   - 通过“扩展”添加了额外的功能
   - 推荐用于新代币

## 在 Anchor 程序中调用 Token Program

[`anchor-spl`](https://github.com/coral-xyz/anchor/tree/v0.30.1/spl) crate 简化了在 Anchor 程序中与 Solana 的 Token Program 交互的过程。此 crate 包含了原始 Token Program 和新版 Token Extension Program (Token 2022) 的指令和账户类型。

只需将 `anchor-spl` crate 添加为您的程序的依赖项，并在 `Cargo.toml` 中将 `"anchor-spl/idl-build"` 添加到 idl-build 特性列表中。有关如何在本地创建 Anchor 程序的步骤，请参阅 [快速入门页面](/docs/quickstart/local)。

```shell title="终端"
cargo add anchor-spl
```

```toml title="Cargo.toml"
[features]
idl-build = [
    "anchor-lang/idl-build",
    "anchor-spl/idl-build",
]

[dependencies]
anchor-lang = "0.30.1"
anchor-spl = "0.30.1"
```

### 核心模块

`anchor-spl` crate 提供的最常用的模块包括：

| 模块                                                                                                    | 描述                                                                              |
| --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| [`token`](https://github.com/coral-xyz/anchor/blob/v0.30.1/spl/src/token.rs)                              | Token Program（旧版）的指令和账户类型                                    |
| [`token_2022`](https://github.com/coral-xyz/anchor/blob/v0.30.1/spl/src/token_2022.rs)                    | Token 2022 基础指令（与 Token Program 功能匹配的指令）     |
| [`token_2022_extensions`](https://github.com/coral-xyz/anchor/tree/v0.30.1/spl/src/token_2022_extensions) | Token 2022 扩展指令                                                       |
| [`token_interface`](https://github.com/coral-xyz/anchor/blob/v0.30.1/spl/src/token_interface.rs)          | 适用于 Token Program 和 Token 2022 Program 的账户类型实现 |
| [`associated_token`](https://github.com/coral-xyz/anchor/blob/v0.30.1/spl/src/associated_token.rs)        | 关联代币账户指令                                                     |
